FRONTEND DEVELOPMENT • UX-FOCUSED PROJECT

TinySteps

TinySteps is a mobile-first maternal health platform designed to help pregnant women in underserved communities find trusted and affordable prenatal healthcare.

The project was developed around the challenge of making it easier for users to find healthcare facilities, explore available services, and book antenatal appointments.

ROLE

Frontend Developer

TECHNOLOGIES

HTML • CSS • JavaScript

FOCUS

Responsive & User-Centered Design

Key Features

  • ~ Search for nearby healthcare facilities
  • ~ Filter facilities by location, cost, and available services
  • ~ View clinic information and hours
  • ~ Book antenatal appointments
  • ~ Receive appointment reminders
  • ~ Access pregnancy tips and information
